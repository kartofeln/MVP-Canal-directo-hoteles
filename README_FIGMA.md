# 🎨 LinkedIn Post + Figma - Sector Turístico

## 🚀 **Resumen del Proyecto**

Este proyecto combina **diseño profesional en Figma** con **contenido optimizado para LinkedIn** para crear posts atractivos sobre datos del sector turístico español.

---

## 📁 **Archivos del Proyecto**

### **🎨 Diseño Figma:**
- `figma_design_guide.md` - Guía completa de diseño
- `figma_specifications.json` - Especificaciones técnicas exactas
- `linkedin_image_generator.html` - Versión HTML para referencia

### **📝 Contenido LinkedIn:**
- `linkedin_post_figma_ready.md` - Textos optimizados para Figma
- `linkedin_post_text.md` - Versiones originales del texto
- `GUIA_LINKEDIN.md` - Guía de uso en LinkedIn

---

## 🎯 **Cómo Usar Figma + LinkedIn**

### **Paso 1: Crear el Diseño en Figma**

1. **Abrir Figma** y crear nuevo proyecto
2. **Importar especificaciones** desde `figma_specifications.json`
3. **Seguir la guía** en `figma_design_guide.md`
4. **Crear frames** con las dimensiones correctas:
   - Post principal: 1200x628px
   - Carrusel: 1080x1080px (4 slides)

### **Paso 2: Aplicar el Diseño**

#### **Frame Principal (1200x628px):**
```
┌─────────────────────────────────────┐
│  🌍 Sector Turístico                │ ← Header con gradiente
│  Datos actualizados de turismo...   │
├─────────────────────────────────────┤
│  📊 Julio 2025                      │ ← Highlight principal
│  Análisis del turismo interno...    │
├─────────────────────────────────────┤
│  🏖️ 🏔️ 🏛️ 🍽️                      │ ← Grid de 4 tarjetas
│  Destinos Turismo Turismo Turismo   │
│  Costeros Rural Cultural Gastronóm. │
├─────────────────────────────────────┤
│  💡 Insights Clave:                 │ ← Caja de insights
│  • Recuperación sostenida...        │
│  • Nuevas tendencias...             │
│  • Impacto de la digitalización...  │
├─────────────────────────────────────┤
│  #TurismoEspaña #SectorTurístico... │ ← Hashtags + CTA
│  📈 Ver análisis completo           │
└─────────────────────────────────────┘
```

### **Paso 3: Exportar y Publicar**

1. **Exportar** como PNG desde Figma
2. **Copiar texto** de `linkedin_post_figma_ready.md`
3. **Publicar** en LinkedIn con imagen + texto
